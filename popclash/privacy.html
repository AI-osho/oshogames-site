POP CLASH — Privacy Policy

Last updated: 26 October 2026 (version 2.0.1)

POP CLASH plays entirely offline. There is no account and no sign-in. Two features are optional and you choose whether to use them: connecting a Solana wallet, and the weekly ranking. Everything else in the game works with the network switched off, exactly as before.

What the app collects on its own

Nothing. There is no analytics, no advertising, no crash reporting and no third-party SDK that transmits data. The app requests no runtime permissions: no camera, microphone, contacts, location, storage or identifiers. Besides internet access, which only the optional ranking uses, the only permission it declares is vibration, for short haptic feedback during matches. Nothing is sent anywhere unless you press a button that says it will.

What the app stores on your device

One save file, held in the app's own private storage. It contains your coins, the equipment you own and have equipped, your skill levels, your quest progress, your chosen language, a count of matches played and won, and — if you have played the weekly challenge — your best record for the current week (how many fighters you beat, and your time) together with the recorded button presses from that run. It also keeps your daily mini-game results, the friend challenge codes you have played, your fighter records and rewards, and your settings (button layout, vibration, flashes, controllers). The save file never leaves your device; only your weekly challenge record is sent, and only if you submit it to the ranking. Uninstalling the app removes it.

If you connect a wallet, the app also stores your wallet's public address and the authorisation token the wallet gave it, so you do not have to approve again every time. Disconnecting removes both. This wallet connection information is not included in Android's cloud backup.

Connecting a wallet (optional)

Connecting uses the Solana Mobile Wallet Adapter, which talks to a wallet app installed on the same device. It does not use the internet. We receive nothing from it, and we never see your private key or seed phrase. The app never asks your wallet to approve a transaction, spend anything, or write to any blockchain — the only thing it ever asks for is a signature that proves you own the address, and only when you submit to the ranking. If you have not connected a wallet yet, pressing SUBMIT opens your wallet app once, to connect and sign together.

If your wallet reports a display name for the account (for example a Seeker ID ending in .skr), the app shows that name instead of your address.

The weekly ranking (optional)

The ranking is the only part of POP CLASH that uses the internet: when you open it, submit to it, or watch the top run. It is off unless you use it.

When you press SUBMIT

The app sends the following to api.oshogames.com, a server operated by OSHO GAMES:

WhatWhy
Your wallet's public addressTo identify the entry as yours. This is public information; it is not a private key.
The display name your wallet reports (e.g. osho.skr), if anyTo show a readable name on the board instead of an address.
The week number, how many fighters you beat, and your timeThe entry itself.
The button presses recorded during that runSo the server can replay the run and confirm the record is real. Without this, any record could be claimed. It is a list of which buttons were held on each frame — nothing else.
A signature made by your walletTo prove the entry came from the owner of that address.
The version number of the gameSo the server replays with the matching version of the game code.

What is sent is a record of that single challenge run. It contains no personal information, no contacts, no device identifiers and nothing about anything else you do on your phone.

When you open the ranking screen

The app requests the current board. If a wallet is connected, your public address is included in that request so the server can tell you your own position. Nothing else is sent.

When you watch the top run

The app downloads that entry's recorded run (the button presses only) from our server and replays it inside the game.

What is stored, and what is public

For each week, and for each version of the game, we keep one entry per wallet address: the address, the display name, how many fighters you beat, the time, the game version, the recorded run, and when it was submitted. The name, how many fighters you beat and the time are shown publicly on the leaderboard inside the game. The leaderboard, and the label shown while a top run is being watched, also show a shortened form of your wallet address (only the first and last few characters), so that players with the same display name can be told apart. The recorded run (the button presses only) of each of the top ten entries on a board can be downloaded from our server by anyone, so that it can be replayed and watched in the game. Other recorded runs are kept so an entry can be re-checked; they are not published.

Entries are kept while the game is in service. You can ask us to delete yours at any time — email the address below from any address, telling us the wallet address to remove.

Seeker Genesis Token check

When you submit, our server checks whether the submitting wallet holds a Seeker Genesis Token (the token given to each Solana Seeker phone). It asks a public Solana RPC service (by default api.mainnet-beta.solana.com) for the public token accounts of your wallet address — information that is already public on the Solana blockchain. The result (whether a token was found, and the token's address) is stored with your entry; a lookup is reused for up to one day. If a token is found, a SEEKER tag is shown next to your name on the ranking, and your entry also appears on the Seeker-only board (one entry per token).

Server logs and backups

Like most web servers, ours keeps access logs (IP address, time and request) for about two weeks (15 days at most) for security, and then deletes them. Submissions that are rejected are recorded with the reason, a short technical note and the wallet address that was sent, and kept for up to 30 days. The ranking data is backed up daily, and backups are kept for 14 days. None of this is combined with anything else or used to build a profile of anyone.

Vibration and controllers

The app can vibrate during matches; you can turn this off in Settings. Game controllers are read only to play. Nothing about either is sent; only your settings for them are saved on your device.

Who else receives anything

There is no analytics provider, no advertising network and no data broker. The ranking server is run by OSHO GAMES and does not share what it holds with third parties. The only outside service it contacts is the public Solana RPC service described above, which receives your wallet address when the server checks for a Seeker Genesis Token. We would disclose information only if we were legally required to.

Children

The game is suitable for all ages and contains no advertising and no purchases. Played on its own it collects nothing, so it collects nothing from children. The ranking requires a Solana wallet, which children are unlikely to have; the only text it can display is the name supplied by a wallet, and there is no chat, messaging or other way for players to communicate.

Changes

If a future version collects anything not described here, this page will be updated before that version is released, and the change will be described here.

What changed in version 2.0.1

The leaderboard now shows a shortened form of each wallet address (the first and last few characters) next to the name, so that players with the same name can be told apart. Your wallet connection information is no longer included in Android's cloud backup. The OSHO GAMES logo at start-up stays on screen a little longer, and the message shown when the ranking server is busy has been reworded. The game does not collect anything new.

What changed in version 2.0

The weekly ranking lists any run that beats at least one fighter, and records how many fighters you beat alongside your time. Boards are kept separately for each version of the game. You can connect a wallet at the moment you submit. The recorded runs of the top entries can be watched by other players. Our server checks for a Seeker Genesis Token when you submit. Daily mini-games, friend challenge codes, fighter records and settings stay on your device.

What changed in version 1.1

Version 1.0 had no network functionality at all. Version 1.1 adds optional wallet connection (which does not use the internet) and the optional weekly ranking (which does). The game still plays in full with the network switched off.
